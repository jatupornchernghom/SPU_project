# ทดสอบ QR พร้อมเพย์ (PromptPay QR Payment)

คู่มือสำหรับเพื่อนร่วมโปรเจกต์ที่อยากลองฟีเจอร์ QR พร้อมเพย์ในหน้า Checkout

## มันทำอะไร

เมื่อลูกค้าเลือกช่องทางชำระเงิน **"QR พร้อมเพย์"** ในหน้า `/checkout` ระบบจะ generate QR code ตามมาตรฐาน **Thai QR Payment (EMV QR Code)** จริง โดยฝัง:

- **บัญชีผู้รับเงินของร้านนั้นๆ** — แต่ละร้านมีเลขบัญชี/PromptPay ID ของตัวเอง (ไม่ใช่บัญชีกลางของแพลตฟอร์ม) เงินจึงโอนตรงเข้าร้าน
- **จำนวนเงิน** ตรงกับยอดรวมของออเดอร์พอดี

สแกนด้วยแอปธนาคารไทยอะไรก็ได้ (K PLUS, SCB Easy, ฯลฯ) แอปจะเด้งหน้าจ่ายเงินพร้อมชื่อผู้รับและยอดเงินที่ถูกต้อง นอกจากนี้ยังกดปุ่ม **คัดลอกเลขบัญชี** ใต้ QR เพื่อก็อปไปจ่ายผ่านแอปธนาคารแบบพิมพ์เองได้ด้วย

### เพราะเงินเข้าบัญชีร้านโดยตรง ระบบจึงต้องให้ร้านยืนยันรับยอดเอง

แพลตฟอร์มไม่มีทางรู้อัตโนมัติว่าร้านได้รับเงินแล้วจริง (ไม่ได้ต่อ API ธนาคาร) ดังนั้น:

1. เมื่อลูกค้ากด "ยืนยันและชำระเงิน" ด้วยวิธี QR พร้อมเพย์ → ออเดอร์จะถูกสร้างทันที (ได้คิว ได้ pickup code) แต่สถานะการชำระเงิน (`paymentStatus`) จะเป็น **`PENDING`**
2. ฝั่งร้านค้า (`/restaurant/dashboard`) จะเห็นป้าย **"รอยืนยันยอดโอน QR พร้อมเพย์"** พร้อมปุ่ม **"ยืนยันรับยอด"** บนออเดอร์นั้น
3. ร้านต้องกด **"ยืนยันรับยอด"** ก่อน ถึงจะกด **"เริ่มปรุง"** ได้ (ระบบจะบล็อกไว้ถ้ายังไม่ยืนยัน)
4. ช่องทางอื่น (Mobile Banking, SPU Wallet) ยังคงเป็น Mock Payment แบบเดิม — ยืนยันอัตโนมัติทันที ไม่ต้องกดยืนยันรับยอด

## วิธีตั้งค่าบัญชีร้าน

1. Login เป็น admin (`admin@spu.ac.th` / `password123`)
2. ไปที่ **Admin > ร้านอาหาร** แล้วกด **"แก้ไข"** ร้านที่ต้องการ
3. กรอกช่อง **"PromptPay ID ของร้าน"** รองรับ 3 แบบ:
   - **เบอร์โทรศัพท์** 10 หลัก เช่น `0812345678`
   - **เลขบัตรประชาชน / เลขประจำตัวผู้เสียภาษี** 13 หลัก
   - **e-Wallet ID** 15 หลัก
4. กดบันทึก

> ⚠️ ค่านี้จะถูกฝังลง QR ที่ลูกค้าทุกคนเห็นได้อยู่แล้ว (ไม่ใช่ความลับในแง่นั้น) แต่มันคือ**เลขบัญชีจริงของร้าน** — ข้อมูลที่ใส่ในฐานข้อมูล (Atlas) ที่ใช้ dev/demo ร่วมกันควรเป็นเบอร์ทดสอบเท่านั้น อย่าใส่เลขบัญชีจริงของใครลงไปโดยไม่ได้รับอนุญาต

ข้อมูล seed เริ่มต้น (`npm run seed`) ใส่เบอร์ placeholder ให้ 3 ร้านไว้แล้ว (`0811111111`, `0822222222`, `0833333333`) — ไม่ใช่บัญชีจริง ใช้ดูโครงสร้างได้แต่สแกนแล้วแอปธนาคารจะไม่เจอบัญชีจริง ถ้าอยากทดสอบสแกนจริงให้แก้เป็นเบอร์พร้อมเพย์ของตัวเองผ่านหน้า Admin ตามขั้นตอนด้านบน

## วิธีทดสอบทั้ง flow

1. Login ด้วย `student@spu.ac.th` / `password123` สั่งอาหารจากร้านที่ตั้งค่า PromptPay ID ไว้แล้ว ไปจนถึง `/checkout`
2. เลือก **"QR พร้อมเพย์"** — QR พร้อมปุ่มคัดลอกเลขบัญชีจะปรากฏ ลองสแกน/คัดลอกดูได้
3. กด **"ยืนยันและชำระเงิน"** → จะพาไปหน้าคิว `/orders/[id]` สถานะออเดอร์เป็น "รับออเดอร์แล้ว" ตามปกติ
4. เปิดอีกแท็บ/เบราว์เซอร์ Login เป็น `restaurant@spu.ac.th` (ผูกกับร้านกะเพรา SPU) ไปที่ `/restaurant/dashboard`
5. ถ้าสั่งจากร้านกะเพรา SPU จะเห็นออเดอร์พร้อมป้าย **"รอยืนยันยอดโอน QR พร้อมเพย์"** และปุ่ม **"เริ่มปรุง" จะกดไม่ได้** (จางลง)
6. กด **"ยืนยันรับยอด"** → ป้ายจะหายไป ปุ่ม "เริ่มปรุง" กดได้ตามปกติ
7. ที่เหลือเหมือน flow เดิม: เริ่มปรุง → พร้อมรับ → ยืนยันรับอาหารด้วยรหัส

## โค้ดที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/lib/promptpay.ts` | สร้าง EMV QR payload string (CRC16 checksum ตามสเปก) + validate/format PromptPay ID |
| `src/components/order/promptpay-qr.tsx` | Client component รับ `promptPayId`/`accountName`/`amount` เป็น props, render QR + ปุ่มคัดลอก |
| `src/models/Restaurant.ts` | field `promptPayId` ต่อร้าน (required) |
| `src/components/admin/restaurant-form-dialog.tsx` | ฟอร์มแอดมินสำหรับตั้ง/แก้ PromptPay ID ของร้าน |
| `src/app/(customer)/checkout/page.tsx` | ดึงข้อมูลร้าน (รวม `promptPayId`) แล้วส่งให้ `<PromptPayQr />` |
| `src/services/order.service.ts` | `createOrder` ตั้ง `paymentStatus: "PENDING"` สำหรับ QR_PAYMENT, `confirmPayment()` ให้ร้านกดยืนยัน, และ gate ไม่ให้เข้าสถานะ "กำลังปรุง" ถ้ายังไม่ยืนยัน |
| `src/app/api/orders/[id]/payment/route.ts` | `PATCH` endpoint สำหรับปุ่ม "ยืนยันรับยอด" (จำกัดเฉพาะ staff ของร้านนั้น/admin) |
| `src/components/restaurant/dashboard-board.tsx` | แสดงป้ายรอยืนยัน + ปุ่ม "ยืนยันรับยอด" บนแดชบอร์ดร้าน |

ถ้าจะทดสอบ payload โดยไม่ผ่าน UI ก็เรียกตรงๆ ได้:

```ts
import { buildPromptPayPayload } from "@/lib/promptpay";

const payload = buildPromptPayPayload("0812345678", 110);
console.log(payload); // string ที่เอาไป encode เป็น QR ได้เลย
```
